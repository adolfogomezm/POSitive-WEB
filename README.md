# POSitive-WEB

Dashboard web para monitorear el estado, productos y ventas de tu negocio. Diseñado para cargar rápido y mantener las sesiones de usuario protegidas.

## Tecnologías

- **Astro** (SSR)
- **TypeScript**
- **Clerk** (Autenticación)
- **Tailwind CSS**

## Instalación y Uso

1. Clonar el repositorio.
2. Instalar dependencias:
   ```bash
   npm install
3. Configurar las variables como se muestra en .env.example
4. Configurar el backend
5. Ejecutar
  ```bash
  npm run dev
